# Arkan Tartys
**Играть:** https://arkan-tarty.netlify.app

Пиксель-арт перетягивание каната в духе Basket Random. Одно устройство, 1P vs БОТ или 1P vs 2P, матч до 2 побед в 3 раундах.

## Идея
Это не «спам двух кнопок»: тяга тратит выносливость, рывок нужно выбирать момент, усталость наказывает за перегрузку, а метроном награждает за такт. Каждый раунд добавляет случайный модификатор и новую площадку.

## Правила и управление
| | Тяга | Рывок |
|---|---|---|
| P1 (красный, слева) | `A` | `S` |
| P2 (синий, справа) | `←` | `↓` |

На телефоне — кнопки «ТЯНУ» и «РЫВОК» под полем (в режиме с ботом только P1).

- Цель: утянуть метку-флаг (`pos` ∈ [-1, 1]) на свою линию: -1 — победа P1, +1 — победа P2.
- Раунд длится 45 секунд. По истечении времени побеждает тот, к чьей стороне ближе метка. Если |pos| < 0.02 — ничья, играется дополнительный раунд.
- Матч — до 2 побед.

## Механика
- **Тяга:** небольшой импульс, −8 выносливости (из 100), минимум 80 мс между тягами. Зажатие игнорируется (`e.repeat`).
- **Рывок:** импульс ≈ ×5, −35 выносливости, нужно ≥ 35, перезарядка 2,5 с.
- **Восстановление:** только без действий: пауза 0,5 с, затем +16/с.
- **Усталость:** при 0 выносливости 1,5 с нельзя тянуть, восстановление вдвое медленнее, персонаж «сидит» и потеет.
- **Ритм-бонус:** тяга «в удар» метронома даёт +30% импульса; лимиты выносливости остаются.
- **Модификаторы** (одинаковы для обоих): «Скользкая площадка» (слабее затухание), «Ветер» (малая постоянная сила в случайную сторону), «Тяжёлый канат» (импульсы ×0.7, восстановление ×1.5), «Турбо» (быстрее и сильнее), «Гигант» (у случайного игрока крупнее персонаж, но расход выносливости +20%). Площадки (двор, пляж, крыша, космос) и внешний вид персонажей — косметика.

## Бот
Бот вызывает ту же функцию `pull()`, что и игроки, поэтому подчиняется тем же лимитам: выносливость, усталость, перезарядка, интервал 80 мс. Сложность меняет только время реакции (Легко ≈ 0,34 с, Норм ≈ 0,22 с, Тяжело ≈ 0,14 с, разброс ±30%) и выбор момента: он отдыхает при малой выносливости и делает рывок, когда канат смещён в его сторону или сил много. Скрытых бонусов и изменения физики нет.

## Архитектура
- Логика `update(dt)` работает с фиксированным шагом 1/60 с (накопитель времени в главном цикле), поэтому скорость игры одинакова на 60 и 144 Гц. `draw()` только читает состояние.
- Конечный автомат: `menu → tutorial → countdown → playing → roundEnd → matchEnd`. Ввод принимается только в `playing` (и `tutorial`).
- Ввод складывается в очередь и обрабатывается в `step()`. Проверки лимитов у каждого игрока независимы, порядок не даёт преимущества P1.
- `reset()` создаёт полностью чистое состояние для нового раунда и реванша.
- Настройки и статистика (победы P1, P2/бот, ничьи, последние 10 матчей) — в `localStorage` внутри `try/catch`.
- Все звуки синтезируются Web Audio API.

## Стек
HTML + CSS + JavaScript, Canvas 2D, Web Audio API, без сборщиков и внешних ассетов. Шрифт [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) (Google Fonts, SIL OFL), запасной — `monospace`. При разработке использовались AI-инструменты (Claude).
